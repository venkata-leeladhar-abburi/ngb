# sections

Page blocks (Hero, ProofStrip, Journey, ToolsBento...). A page is a list of sections; a section is a composition of `@ngb/ui` components.

- Built with `/build-section <screen id>`; targets and copy are in `.claude/skills/build-section/screens.md`.
- Only `@ngb/ui` components and token utilities. No raw values (lint blocks them). Never imports `@/server`.
